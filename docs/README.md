# Pre-publication drafts

With Springer's permission, drafts of *Foundations and Pitfalls in Epidemic Modeling: An Introduction to
Formulating, Analyzing, and Fitting Models* (James M. Hyman, Zhuolin Qu, and Ling Xue) are posted here for comment
while the book is under review.

Every file carries the draft version in its name, and the same version is printed on the draft's title page. When
you send feedback, please name the version you read, so we can match your comments to the right pages.

**Current draft: v2_108_2** (559 pages, 2026-10-23).

| File | Contents |
|---|---|
| [`hyman2026avoiding_v2_108_2.pdf`](hyman2026avoiding_v2_108_2.pdf) | The draft, v2_108_2: the application chapters written from the infected viewpoint, sensitivities in durations, and every exercise checked against the text |
| [`AUDIT_LEDGER_v2_108_2.md`](AUDIT_LEDGER_v2_108_2.md) | The claim audit ledger as of v2_108_2, adding the corrections since v2_104_1 |

Each new draft replaces the previous one; the repository [changelog](../CHANGELOG.md) records each change, and the
ledger keeps every earlier correction. A draft is not the published book, and its page numbers will change.

Please report errors or send comments through the
[issue tracker](https://github.com/machyman/hyman2026avoiding/issues/new/choose).
