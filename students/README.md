# Student materials

Companion materials for Part I of *Learning with AI: A Framework for Students, Instructors, and
Universities* by James M. Hyman (SIAM Books).

Start with **Start here** if you are new to using AI for coursework. The rest can be read in any order.

| Material | What it is |
|---|---|
| [start-here.md](start-here.md) | Orientation for a student new to using AI for coursework |
| [from-answers-to-learning.md](from-answers-to-learning.md) | The switch from extracting answers to building understanding |
| [study-sessions/](study-sessions/) | Four worked study sessions: statistics, coding, physics, mathematics |
| [undergraduate-research.md](undergraduate-research.md) | Using AI in a first mentored research project (REU, thesis, lab, poster), and the on-ramp to the graduate standard |
| [sharing-ai-conversations.md](sharing-ai-conversations.md) | How to share a read-only chat link with an instructor, by platform |
| [checklist.md](checklist.md) | The pre-submission checklist from Part I |
| [disclosure-templates.md](disclosure-templates.md) | Short and fuller AI-use disclosure statements |

Two prompts you may want alongside these live in [`companion/`](../companion/): the Study Partner
Protocol and the layered-explanation prompt.
